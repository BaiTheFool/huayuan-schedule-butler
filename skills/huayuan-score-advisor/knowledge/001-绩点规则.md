# 绩点规则（官方口径）

> 依据《华南理工大学全日制本科学生学籍管理办法（2026 年修订）》（华南工教〔2026〕22 号）第 39 条、《学士学位授予实施细则（2025 年修订）》第 5 条。以官方最新通知为准。

## 一、两类平均学分绩点（第 39 条）

为反映学习质量，学校采用**平均学分绩点**作为评价指标，分两类，**用途不同、口径不同，不可混用**：

### 1. 百分制平均学分绩点

```
百分制平均学分绩点 = ∑(课程百分制成绩 × 课程学分数) / ∑课程学分数
```

| 要点 | 规定 |
|---|---|
| 用途 | **校内**推荐免试研究生（推免）、转专业等 |
| 课程范围 | 主修专业综合培养计划要求的**必修课程** |
| 成绩口径 | 按**首次考核**取得的课程成绩计算 |
| 不及格/不通过 | 百分制成绩记 **0** |
| 重考通过 / 重修通过 | 百分制成绩记 **0** |
| 缓修/缓考通过 | 可计算在修读学期的百分制平均学分绩点内 |

**五级计分制折算**：优秀 = 95，良好 = 85，中等 = 75，及格 = 65，不及格 = 0。
**两级计分制折算**：通过 = 80，不通过 = 0。

### 2. 四分制平均学分绩点（GPA）

```
GPA = ∑(课程绩点 × 课程学分数) / ∑课程学分数
```

| 要点 | 规定 |
|---|---|
| 用途 | 申请**出国**开具成绩证明等 |
| 课程范围 | 主修专业综合培养计划要求的课程；**通识教育课程、辅修课、校外课程不纳入** |
| 成绩口径 | 按学生考核取得的**最高**课程成绩计算绩点 |
| 等级来源 | **动态转换规则**：按课程班成绩分布（排名百分位）定等级 |
| 重考 | 绩点认定区间以**原班级正考成绩区间**为准，但**封顶 3.3** |

## 二、学校成绩标准（动态转换规则，第 39 条附表）

### 百分制 → 等级 → 绩点（按课程班排名百分位）

| 课程班排名位置 | 等级 | 课程绩点 |
|---|---|---|
| 前 20% | A | 4.0 |
| 20.1% ~ 35% | B+ | 3.7 |
| 35.1% ~ 50% | B | 3.3 |
| 50.1% ~ 60% | B- | 3.0 |
| 60.1% ~ 70% | C+ | 2.7 |
| 70.1% ~ 80% | C | 2.3 |
| 80.1% ~ 90% | C- | 2.0 |
| 后 10% | D | 1.7 |
| 不通过 | F | 0.0 |

> 该表按**课程班内排名**而非绝对分数判定（“动态”即此意）。同一百分制分数在不同班级可能得到不同等级；没有班级成绩分布就无法精算 GPA。

### 五级制 → 绩点

| 五级制 | 等级 | 课程绩点 |
|---|---|---|
| 优秀 | A | 4.0 |
| 良好 | B | 3.7 |
| 中等 | C | 2.7 |
| 及格 | D | 1.7 |
| 不及格 | F | 0.0 |

### 二级制 → 绩点

| 二级制 | 等级 | 课程绩点 |
|---|---|---|
| 通过 | P | 3.0 |
| 不通过 | F | 0.0 |

## 三、学位授予要求（学士学位授予实施细则第 5 条）

取得毕业资格且**按四分制平均学分绩点计算方法，主修专业综合培养方案内全部课程（辅修课程、校外课程除外）的平均学分绩点 ≥ 2.0**，方可授予学士学位。

## 四、常见口径问答

- **问**：重考/重修过了，为什么绩点是 0？→ 百分制绩点按首次考核计，重考/重修通过记 0（第 39 条说明 ④）；GPA 按最高成绩，但重考绩点封顶 3.3。
- **问**：通识课算不算 GPA？→ 四分制 GPA **不算**（仅主修培养方案课程）；百分制绩点只算必修课。
- **问**：选修课算吗？→ 百分制绩点只算必修课；GPA 指“主修专业综合培养计划要求的课程”（必修+专业要求课程），通识/辅修/校外不算。
- **问**：免修考核成绩怎么算？→ 免修考核 75 分及以上取得学分并记载成绩，低于 75 分需重新修读（学分制办法第 23 条）。
