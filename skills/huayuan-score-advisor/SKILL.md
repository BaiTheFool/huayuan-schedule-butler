# 华园绩点与操行分顾问技能

内置官方口径知识库与计分工具，数据来自《华南理工大学 2026 年本科生手册》中《学籍管理办法（2026 年修订）》《学分制教学管理实施办法（2025 年修订）》《本科生综合测评及奖励办法（2025 年修订）》《推荐优秀应届本科毕业生免试攻读研究生管理办法（2026 年修订）》《学士学位授予实施细则（2025 年修订）》。

## 何时使用

用户问到以下主题且需要给出**基于官方规则**的答案时，先查本知识库，涉及具体计算时调用对应脚本：

- 绩点 / 平均学分绩点 / GPA / 加权平均分 / 成绩怎么算
- 操行分 / 综合测评 / 德育智育体育美育劳育积分 / 加分扣分
- 奖学金门槛（国家奖学金 / 励志 / 学校奖学金 / 荣誉称号 / 体测要求）
- 保研（推免）成绩条件与综合评价分测算
- 学位授予的绩点要求（GPA ≥ 2.0）
- 课程成绩折算（五级制 / 二级制 → 百分制 / 绩点）

**分工边界**：社区版生存手册知识库 `huayuan-campus-manual` 也有绩点/综测条目（`007-绩点GPA.md`、`008-科创与人文素养分.md`），本技能以**官方手册条文**为准，两者冲突时以本技能 + 学校最新官方通知为准，并把差异记入项目根 `ERROR_LOG.md`。课表/作业等实时平台数据仍走 `huayuan-browser-session`。

## 计分工具

```powershell
# 绩点计算器：百分制平均学分绩点 + 四分制 GPA + 学位检查
node skills\huayuan-score-advisor\scripts\gpa-calculator.js --input <成绩文件.json>
node skills\huayuan-score-advisor\scripts\gpa-calculator.js --self-check        # 固定样例回归

# 综合测评计算器：H = 0.7X + 0.1C + 0.2S，含操行分 C1/C2 与德智体美劳
node skills\huayuan-score-advisor\scripts\conduct-calculator.js --input <测评输入.json>
node skills\huayuan-score-advisor\scripts\conduct-calculator.js --self-check    # 固定样例回归
```

输入文件结构与计分口径见各脚本头部注释和 `knowledge/` 对应知识文件。**所有样例均为虚构数据**；真实成绩属于个人隐私，只在本机计算，不落盘到项目产物。

## 使用纪律

1. **标注来源**：给出规则时注明「依据《2026 年本科生手册》相关办法，以官方最新通知为准」。
2. **区分两类绩点**：百分制平均学分绩点（保研/转专业用，按首次考核成绩、重修重考记 0）与四分制 GPA（出国用，按最高成绩、动态转换）不可混用。
3. **四分制 GPA 是动态转换**：按课程班成绩分布（排名百分位）定等级，没有班级分布时不能凭空给 GPA，只能给「估算/示例」并说明。
4. **综合测评以院（系）实施细则为准**：校级办法给权重与上限，各院（系）可在细则中微调加分认定，回答时提醒「具体加分以院（系）细则为准」。
5. **不说假话**：知识库没有的内容直接说没有，回源手册或学校官网，不编造。

## 维护

- 知识文件与 `scripts/` 中的计分常量表是**双份事实源**：改了规则必须两边同步（脚本常量 + 知识文件），并在 `ERROR_LOG.md` 记档。
- 新增知识文件时：编号续排、命名保持 `NNN-主题.md`，并在 `000-索引.md` 速查表加一行。
- 上游（学校）规则更新时：先以官方最新文件为准修订本技能，再更新 `000-索引.md` 的同步日期。
