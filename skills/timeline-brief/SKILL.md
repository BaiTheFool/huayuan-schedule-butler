# 简洁时间轴（timeline-brief）

## 这个技能做什么

把 `now.json` / `plan.json` / `schedule-analysis.json` **已有的结论**压成一条时间轴。
它**不做任何重新规划**：不调用大模型、不联网、不排序新逻辑，只是裁剪与排版，
所以正常情况下 1 秒内出结果。

## 什么时候用

| 场景 | 是否调用 |
|---|---|
| 用户说「给我今天的时间轴 / 看一下今天安排 / 时间轴」 | ✅ 调用 |
| 用户说「详细计划 / 导出计划」 | ✅ 调用，并输出完整版本 |
| 初始化完成后展示一次紧凑驾驶舱 | ✅ 由驾驶舱内部调用 |
| 用户完成 / 延后 / 临时新增后 now.json 重新生成 | ✅ 刷新时调用 |
| 普通问答（"我现在该干什么""今晚还有多少时间"） | ❌ 默认不生成时间轴 |
| 平台读取进行中 | ❌ 读完才调用 |
| 未初始化 | ❌ 先引导初始化 |

## 怎么用

```powershell
node <本技能目录>\scripts\timeline-brief.js --output-dir out              # 默认：现在 + 接下来 6 小时
node <本技能目录>\scripts\timeline-brief.js --output-dir out --hours 3    # 只看接下来 3 小时
node <本技能目录>\scripts\timeline-brief.js --output-dir out --json       # 拿结构化行数据自己排版
node <本技能目录>\scripts\timeline-brief.js --self-check                  # 离线自检（10 项）
```

## 输出格式（固定，不要加装饰）

每行四段：`时间 | 事项 | 来源 | 优先级或状态`

```
14:20—14:30 前往教室 [课程] 上课
14:30—16:10 生产运作管理（样例） [课程] 上课
16:10—17:40 第 6 章作业（样例） [任务] P0
19:00—20:00 可安排 [空闲] 空闲
```

约束：

- 默认只输出「现在 + 接下来 6 小时」；
- **最多 8 行**；
- 来源只用 `[课程] [任务] [偏好] [临时] [待确认]`（空闲用 `[空闲]`）；
- 不生成 SVG、图片、大表格；
- 不重复课程数、待办数这类摘要（用户明确要才有）；
- 数据未确认时首行写「（数据未确认，以下为估算）」，不能冒充正式计划。

## 不做什么

- 不联网、不登录、不读学校系统；
- 不写 HTML 文件、不起本地服务；
- 不修改 `now.json` / `plan.json`，只读取。
