# 任务耗时基线

用于「预计耗时」字段的初始估算。**基线只是起点**：用户说过一次的偏好要记住并覆盖基线。

| 任务类型 | 基线耗时（分钟） | 说明 |
|---------|----------------|------|
| 常规课后作业（计算 / 证明题） | 60-90 | 按一次作业 5-8 题估 |
| 编程实验 | 120-180 | 不含调试卡壳 |
| 大型编程项目 / 课程设计 | 480-900 | 必须拆成 ≥3 个阶段排入不同天 |
| 实验报告 | 90-150 | 含数据处理与作图 |
| 课程论文 / 读书报告 | 240-420 | 建议拆成"读材料 40% + 写作 50% + 校对 10%" |
| 小组任务（个人份额） | 60-120 | 不含协调时间；另加 30 分钟沟通缓冲 |
| 考试复习 | 单科 120-300 | 按 3-5 个专题，每个专题 40-60 分钟 |
| 测验（线上小测） | 30-45 | 需留出登录与掉线重试余量 |
| 阅读材料（单篇论文 / 章节） | 40-70 | |
| 报名 / 通知待办 | 10-20 | 耗时短但**漏掉代价高**，优先级不低 |

## 缓冲规则

| 场景 | 建议缓冲 |
|------|---------|
| 任务之间切换 | 15 分钟 |
| 连续两个深度任务（编程 / 论文）之后 | 30 分钟休息 |
| 上课前 | 10 分钟 |
| 截止时间前的安全余量 | 至少提前 1 个可用时段完成，不排在截止当天 |

## 单日负荷参考

| 身份 | 默认单日可安排上限 | 说明 |
|------|-----------------|------|
| 本科生 | 240 分钟 | 含课间碎片时间利用；可在偏好里改成自己的上限（默认档案用 210 分钟） |

## 用户偏好字段（第一次排程时询问，之后复用）

- 每天不可用时段（如 23:30 后、午休 12:30-13:30）
- 运动 / 休息的固定时段与时长
- 周日是否留空
- 偏好上午还是晚上做深度任务
- 单日负荷上限（是否要低于默认值）

这些偏好一旦确认，写进计划开头的一句话摘要里，方便用户核对。
