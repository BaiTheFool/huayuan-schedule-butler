# 分屏网页驾驶舱

## 用途

当用户需要一边对话、一边查看完整可视化时，启动本机网页驾驶舱。网页只负责展示，不接收聊天，不调用 Agent，不写入学校系统。

## 触发

专家收到用户任何有效指令后，都必须先执行本技能，再处理原请求。用户没有提到驾驶舱也要打开；用户只要求“看卡片”时，先打开侧边驾驶舱，再按需生成内嵌卡片。

未初始化、没有 `now.json` 不是跳过理由。启动器会打印：

```text
LIVE_DASHBOARD_ONBOARDING_MODE:1
LIVE_DASHBOARD_READY:http://127.0.0.1:<端口>/
```

## 执行

1. 直接启动；不要先调用 `now.js`，也不要求用户先找文件：

```powershell
node <本技能目录>\scripts\launch-dashboard.js --no-open
```

启动器只创建本地服务，不直接拉起外部浏览器。读取输出：

- `LIVE_DASHBOARD_SIDEBAR_FILE`：启动器在本次会话工作区生成的跳板 HTML 绝对路径；它打开后立即重定向到本地驾驶舱；
- `LIVE_DASHBOARD_ALREADY_OPEN:0`：先处理原请求；本轮完成时，最后一个工具调用必须是 `present_files({"files":["<LIVE_DASHBOARD_SIDEBAR_FILE>"]})`，在右侧内置浏览器面板打开；
- `LIVE_DASHBOARD_ALREADY_OPEN:1`：侧边页面仍在线，不要重复打开；
- 禁止再次运行启动器，禁止去掉 `--no-open`，禁止打开外部浏览器；`present_files` 后只写最终文字，不再调用工具。

2. 看到 `LIVE_DASHBOARD_READY:<url>` 后，在处理原请求的回答里保留一行：

> 驾驶舱已打开：`<url>`

用户问手机、手机连接或手机安装时使用 `--page mobile`，直接定位到第四个“手机工作台”标签：

```powershell
node <本技能目录>\scripts\launch-dashboard.js --no-open --page mobile
```

拿到 `LIVE_DASHBOARD_SIDEBAR_FILE` 后，完成手机相关处理后用 `present_files({"files":["<SIDEBAR_FILE>"]})` 作为最后工具调用，不启动外部浏览器。

驾驶舱里的“重新导入课表”直接读取教务时，需要 WorkBuddy 允许本专家运行本地命令并启动浏览器。受限环境若返回 `EPERM`，不要要求用户永久开启全部权限；引导其点击页面上的“复制教务读取指令”，在左侧对话完成读取，或使用“本地文件”作为备用。

## 页面内容

- **初始化中心**：今日页顶部列出学院、四平台授权、作息偏好、教学周、课表、待办和活动数据的完成状态；缺失项带红点与“复制补全指令”。
- **双层红点**：导航标签红点表示该页还有未补齐项；进入页面后，具体缺失卡片和字段旁仍有红点。
- **未初始化模式**：没有 `now.json` 时仍打开完整驾驶舱，主页显示“从 0 开始”的复制指令，并保留路线、待办、活动和手机页入口。
- **手机工作台标签**：第四个标签可启动/停止手机只读服务、换配对码、显示局域网地址、检查自动发现端口并下载 APK；未初始化时红点提示先补齐资料。
- 当前唯一第一动作、平台同步提醒、数据待确认项；
- 三个“下一句可以这样问”的复制按钮；
- 大学城校园地图与当前路线；
- 学习 / 放松 / 运动权重条和四种日程画像；
- 天气、考试复习、手动待办、分钟级时间轴；
- “我现在在”楼栋搜索选择器：支持楼栋编号、中文名、学院别名包含匹配，并立即按所选地点重算路线；
- 自动读取同一会话目录中的真实 `jw-timetable.json`、专业偏好和主任务池。
- 本地已经有课表时，首页直接应用最新文件，按钮显示“重新导入课表”；点击后由本机服务调用教务只读脚本，缺登录才打开 Chrome。手选“本地文件”仅作备用。

页面保留三个核心标签，并新增手机引导标签：

- `/`：今日安排。第一屏采用大学城路线 UI，路线、地图、权重条、第一动作和实时摘要同时存在；
- `/todo.html`：全部待办，按 P0/P1/P2/P3 分组，并单独展示已过期项。
- `/activities.html`：校团委、学生工作处、本科生院、研究生院、软件学院与就业在线的公开可参与事项。
- `/mobile.html`：手机连接控制、配对码、局域网地址、APK 下载与故障排查。

首页不是第四个页面，也不另开“路线标签”；路线就是“今日安排”的主体。项目范围仅限华南理工大学大学城校区，明确不属于大学城的课表会被拒绝，不会硬套校园 POI。

活动页读取初始化时选择的学院，支持按“校级 / 我的学院”和事项类型筛选。未选择学院时只展示校级来源，并提示用户在对话中补选。

全部待办页显示最近一次平台数据刷新时间，默认建议每 7 天刷新一次。未初始化时显示“尚未读取平台数据”，共享红点组件提供初始化入口。页面提供固定复制指令：

```text
刷新我的校园待办：请重新读取教务、eCourse、雨课堂和校园门户，更新待办与日程，并告诉我新增、临近截止、已过期和发生变化的事项。
```

复制后由用户本人发到 WorkBuddy 对话区；网页不能自动发送消息。

活动页同样提供固定刷新指令：

```text
刷新校园活动：请重新拉取校团委、学生工作处、本科生院、研究生院、软件学院和就业在线的公开活动公告，筛出仍可报名的活动，并按截止时间排好。
```

复制按钮只复制到剪贴板，不自动发送；用户仍需回 WorkBuddy 对话区输入。

## 安全与边界

- 服务只绑定 `127.0.0.1`；
- 只读取 `now.json`，不读取浏览器 Cookie、密码或身份信息；
- 不提供聊天输入框；
- 不提供提交、报名、缴费、删除或修改学校业务数据的按钮；
- 端口冲突时自动尝试下一个本地端口；
- 页面每 2 秒读取一次最新 `now.json`，对话区更新后右侧自动刷新。
