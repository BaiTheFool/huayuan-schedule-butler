# 手机连接傻瓜教程（给用户照着做）

> 给专家用的话术稿：用户问「手机上怎么用」「怎么装到手机」时，**一次只给一条路线**，
> 优先推荐路线 A（同 Wi-Fi 浏览器），用户明确说想装 App 再给路线 B。

## 0. 先确认电脑这边在跑

在 WorkBuddy 里说「打开手机工作台」，等专家回三行：

```text
MOBILE_REMOTE_READY:http://<电脑IP>:<端口>/
MOBILE_REMOTE_PAIR:<6 位配对码>
MOBILE_REMOTE_DISCOVERY:udp://4327
```

有 `MOBILE_REMOTE_READY` 就说明服务已起；没有就说明没启动成功，先解决启动问题，别让用户去折腾手机。

---

## 路线 A：同一个 Wi-Fi，用浏览器打开（最快，30 秒）

1. 手机连上**和电脑相同的 Wi-Fi**（不要用流量）。
2. 手机浏览器地址栏输入电脑给的那串地址，例如 `http://192.168.1.23:4320/`，回车。
3. 页面出现「手机工作台」，把电脑上显示的 **6 位配对码**输进去，点「连接电脑」。
4. 进入「今日安排」就成功了；以后同一台手机直接打开地址即可，不用再输。

想有桌面图标（可选）：浏览器菜单 →「添加到主屏幕」。

## 路线 B：装安卓 App（推荐长期用，能自动找电脑）

1. 先按路线 A 打开页面（或直接扫电脑上的地址）。
2. 在配对页底部点 **「装到手机桌面（可选）」** → 下载 `huayuan-workbench.apk`。
   也可以直接在手机浏览器输入 `http://<电脑IP>:<端口>/download/app.apk`。
3. 下载完点开安装；如果提示「未知来源」，在弹窗里允许这一次（只装这一个 App）。
4. 打开「华园工作台」：**它会自动列出同一个 Wi-Fi 下的电脑**，点那一条，输 6 位配对码。
5. 以后电脑换了 IP 也不用改地址：打开 App 会自动重新找；找不到时错误页点「电脑换了 IP？点这里重新查找」。

> 只在安卓上装 App；iPhone 用路线 A +「添加到主屏幕」即可。

## 路线 C：手机不在同一个网络（用流量 / 不在学校）

1. 让电脑端带隧道启动：`start-mobile.cmd -Tunnel`，或专家在 WorkBuddy 里加 `--tunnel` 启动。
2. 终端会多一行 `MOBILE_REMOTE_PUBLIC:https://xxxx.trycloudflare.com`。
3. 手机用**这一行 https 地址**打开，输同一个配对码。
4. 如果 https 地址打不开：手机可能解析不了 `trycloudflare.com`，改用 awl / Tailscale 这类虚拟组网，
   手机里填电脑的组网地址（awl 通常是 `10.66.0.2`，以手机 App 里显示的为准）。

## 打不开时按这个顺序排查（不要跳步）

1. **地址对不对**：以电脑终端最新一次输出为准，端口可能不是 4320（被占时会顺延）。
2. **是不是同一个 Wi-Fi**：手机用流量时局域网地址一定打不开，走路线 C。
3. **防火墙**：Windows 第一次监听会弹窗，选「允许专用网络」；没弹窗就手动放行：

   ```powershell
   netsh advfirewall firewall add rule name="Huayuan Mobile 4320" dir=in action=allow protocol=TCP localport=4320
   ```

4. **配对码错了**：输错 8 次会锁 5 分钟；让电脑重启一次工作台会换新码。
5. **页面能开但一直转圈**：多半是手机存了旧令牌，设置页「解除这台手机的配对」后重新输码。
6. **电脑换过 Wi-Fi / 重连过**：电脑的局域网 IP 会变，重新用最新地址，或让 App 重新发现。

## 一句话讲清安全

手机端只读：不能交作业、报名、缴费、改课表；数据只在你自己电脑上，公网隧道只是转发。
要停就在电脑上双击 `stop-mobile.cmd`。

## 给用户的回复模板（不超过 3 行）

> 手机连同一个 Wi-Fi，浏览器打开 `http://<IP>:<端口>/`，配对码 `<6 位>`。
> 想要桌面图标就点页面底部的「装到手机桌面」下载 App，装好后它会自动找到电脑。
> 只读，不会改你的课表；要更新数据回来跟我说「刷新我的校园待办」。
