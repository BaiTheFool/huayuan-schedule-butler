# 20 项扩展 · 当前实现与路线图

> 本次交付聚焦**大学城校区一日路线**（原始需求里的“食堂/图书馆/热水 + 课表 + 卷/玩/运动 + 地图 + GPS + 天气”）。
> 下面把 20 项逐条标清楚：哪些已经能用、哪些复用了现有模块、哪些还没做。
> **没有做的项不会在对话里假装完成。**

## 四、建议的下一步（按性价比）

2. **#13 校车班次**：先做“五山↔大学城”静态时刻表 + 跨校区缓冲，不做实时公交。
3. **#5 课程资料入口**：把 eCourse 课程页 URL 绑到路线里的课程块，点击直达。
4. **#3 冲突精细版**：在现有 `schedule-analyze` 上补“作业截止 vs 晚课/实验”和“连续高密度任务”。
5. **#2 耗时统计**：先记录“预估 vs 实际”，积累 2–3 周再做同类推荐，避免拍脑袋。

## 五、边界

- 只读学校数据，不代交作业、不报名、不签到、不改教务。
- GPS 只在用户点击后读取，本地换算，不上传、不落盘。
- 地图是按真实 POI 经纬度绘制的示意图，不替代导航；不接实时路况。
- 图书馆/热水/门禁为官方来源；饭堂/体育馆时段标“以现场为准”。
- 五山/广州国际校区会返回 `CAMPUS_UNSUPPORTED`，不硬套大学城。
